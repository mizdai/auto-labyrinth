# モンスター画像 制作指示書

画像生成AIにモンスターのドット絵を描いてもらうための資料です。
「共通の指示」を毎回プロンプトの先頭に付け、その後ろに各モンスターの行の内容を続けてください。

## 共通の指示（毎回プロンプトに含める）

```
Pixel art sprite of a fantasy dungeon monster for a retro 8-bit style RPG.
64x64 pixel sprite, upscaled 8x to 512x512 with nearest-neighbor (each pixel = 8x8 block, perfectly square, aligned to a grid).
Limited palette: max 16 colors. No anti-aliasing, no gradients, no dithering blur, no soft shadows, 1-pixel dark outline.
Front view facing the viewer, full body, centered, no cropping.
Solid flat magenta background (#FF00FF), no floor, no scenery, no text, no frame.
```

日本語で指示する場合の例：

```
レトロな8ビット風RPGのモンスターのドット絵。
64×64ピクセルのスプライトを、ニアレストネイバーで8倍に拡大した512×512の画像
（1ピクセル＝8×8の正方形ブロック、グリッドに揃える）。
16色以内、アンチエイリアス・グラデーション・ぼかしなし、1ピクセルの暗い輪郭線。
正面向き、全身、中央配置、見切れなし。
背景は単色のマゼンタ（#FF00FF）のみ。床・背景・文字・枠は描かない。
```

### サイズ区分とキャンバス内での大きさ

キャンバスは全モンスター共通で 64×64 です（ボスのみ 96×96 の指定も可）。
サイズ感は「キャンバスの高さに対して体がどれだけを占めるか」で指示してください。

| 区分 | 実際の大きさの目安 | キャンバス内の高さ | プロンプトへの追記例 |
|---|---|---|---|
| S | 人の膝くらいまで | 約40%（25px前後） | `small creature, occupies about 40% of the canvas height, lots of empty space around it` |
| M | 人間と同じくらい | 約70%（45px前後） | `human-sized, occupies about 70% of the canvas height` |
| L | 人の1.5〜3倍 | 約90%（58px前後） | `large creature, fills about 90% of the canvas height` |
| XL | 見上げるほど巨大 | ほぼいっぱい（足先・翼・角まで枠内に収める） | `huge creature, fills almost the entire canvas, but the whole body fits inside` |

### 注意点

- 既存のゲーム名・作品名をプロンプトに入れないでください（特定作品の模倣になるのを避けるため）。
- ファイル名は表の「ID」に合わせてください（例：`rat.png`）。
- 生成AIの出力は、ピクセルの大きさが不揃いになりがちです。受け取った画像は、こちらで 64×64 に縮小（ニアレストネイバー）し、マゼンタを透明にして取り込みます。

## 第2版：全面作り直しの追加依頼（第1版と同じ会話の続きで使う）

第1版を作った会話の続きに、そのまま貼り付けて使う文面です。基本仕様（ドット絵・マゼンタ背景・9列×5行・並び順）は第1版から引き継ぐ前提で、変更点だけを伝えます。

```
ありがとうございます。この45体を、全部描き直してください。
基本の仕様は前回と同じです（ドット絵、単色マゼンタ背景、9列×5行の1枚のシート、並び順も前回と同じ）。
変更点は次のとおりです。

1. 全身を描く
   ・どのモンスターも、頭のてっぺんから足先（尾・翼・角・武器の先）まで、すべてマスの中に収めてください。
   ・特に前回、体の一部が切れていた次のモンスターは必ず全身にしてください：
     豚鬼の戦士（足まで）、上級魔神（足まで）、洞窟トロル（足まで）、牛頭鬼（足まで）、霜の巨人（足まで）。
   ・足元とマスの下端の間には、少し（マスの高さの5%程度）余白を残してください。
   ・全モンスターの足元（接地点）の高さを揃えてください。浮いているもの（コウモリ・鬼火・炎の精など）は、地面から少し浮いた位置に。

2. 頭身を上げて、写実寄りにする
   ・デフォルメを弱め、実際の生き物や人体に近い比率にしてください。
   ・人型（追い剥ぎ・呪術師・骸骨兵・魔術師・司祭・暗殺者など）は7〜8頭身。
   ・獣・竜・虫も、頭が大きすぎない自然な体型に。
   ・絵柄の雰囲気（暗いダンジョンの色調、細かい陰影）は前回のまま保ってください。

3. 大きさの関係を守る（全員同じ倍率で表示するので、マスの中の大きさがそのままゲーム内の大きさになります）
   ・S（大ネズミ・コウモリ・粘塊・小鬼・骨犬・野犬・毒蛇・蜘蛛・甲虫・鬼火など）：マスの高さの約40%。周りに余白を大きく残す。
   ・M（人間大）：マスの高さの約70%。
   ・L（トロル・牛頭鬼・合成獣・岩の巨像・若き竜・下級魔神・毒竜）：約90%。
   ・XL（霜の巨人・古の竜・上級魔神・深淵の主）：ほぼマスいっぱい。ただし全身が収まるように。
   ・横長の生き物（ネズミ・コウモリ・蛇・トカゲ）も、上の大きさを超えないようにしてください。特に洞窟コウモリは、翼を広げてもマスの幅の半分程度に。
   ・犬頭の小鬼と小鬼の戦士は「小鬼」なので、人間より小さく（Sサイズ）描いてください。

4. 向き
   ・基本は正面か、やや斜め前向き。大ネズミ・飢えた野犬・毒蛇・石眼トカゲは、斜め前から見た姿勢にしてください。

5. その他
   ・マスとマスの間の黒い区切り線は、前回と同じでかまいません。
   ・文字・床・影・背景の装飾は入れないでください。
```
