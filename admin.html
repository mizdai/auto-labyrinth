アクセストークンについて

GitHub の Settings → Developer settings → Personal access tokens → Fine-grained tokens で、 このリポジトリだけを対象に「Contents: Read and write」の権限を付けたトークンを作って貼り付けてください。 トークンはこの端末のブラウザにだけ保存し、GitHub 以外には送りません。
